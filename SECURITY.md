# Security policy

## Supported versions

Security fixes are provided for the latest published minor version.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Include the
affected command, a minimal local reproduction, impact, and any suggested
mitigation. Do not open a public issue for an unpatched vulnerability.

Reports are acknowledged within five business days. A remediation timeline is
shared after validation. Please avoid accessing data that is not yours while
testing.
