# Changelog

All notable changes to PolyPlugin Forge are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

- Added a canonical `plugin.yaml` parser, strict schema, semantic policy, and
  redacted secret scanning.
- Added complete MCP, VS Code, Chrome MV3, and OpenAPI webhook templates in
  versions 1.0.0 and 1.1.0.
- Added native manifest generation and linting, publish preflight, compatibility
  matrix reporting, and non-destructive three-way template upgrades.
- Added a typed library API and human or JSON CLI output.
- Added unit, integration, Playwright E2E, template, demo, benchmark, package,
  security, and release verification.
- Added bilingual documentation, architecture and threat-model references,
  checked-in examples, a real UI screenshot, and a dated public-repository
  comparison.
