# Hello VS Code

Registers a real VS Code greeting command.

This project is a small, zero-dependency VS Code extension generated by
PolyPlugin Forge. It contributes the `hello.vscode` command, which displays and
returns a deterministic greeting.

## Run locally

Requirements: Node.js 22 or newer and VS Code 1.95 or newer.

```bash
npm ci
npm test
npm run build
```

Open the generated folder in VS Code, run the extension host, and invoke
`hello.vscode` from the Command Palette. VS Code provides its API at runtime;
there is deliberately no downloaded `vscode` package.

The extension entry point is `src/extension.js`. `npm run build` copies the
tested source to `dist/extension.js`, which is the entry point declared in
`package.json`.

## Testing

The tests inject a minimal VS Code-compatible host and verify command
registration, invocation, the displayed message, and disposal. They do not use
network access or global state.

## Privacy and security

The generated command runs locally, requests no PolyPlugin permissions, sends no
telemetry, and retains no data. See [docs/PRIVACY.md](docs/PRIVACY.md) before
adding storage, network access, or analytics.

## Package

Generated package identity: `hello-vscode`.
